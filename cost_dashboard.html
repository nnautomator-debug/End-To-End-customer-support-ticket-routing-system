Turn every support ticket into a faster, cheaper decision.

A hybrid Random Forest + MiniLM + LLM judge + RAG workflow that prioritizes tickets, audits itself, and drafts a grounded response for the next action.

What this project proves

Production-shaped thinking: model inference, structured LLM oversight, retrieval, feedback capture, observability intent, and a cost model connected to an operating scenario.

From raw ticket to operational action

Built for multilingual customer-support triage: the body is embedded with MiniLM, categorical routing features feed a balanced Random Forest, a Groq judge audits severity, and FAISS retrieves a grounded answer. Disagreements are captured in DuckDB during a temporary 2–3 month learning window, then the judge footprint can shrink.
